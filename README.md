# オーディン丹波店

明るい配色の宅配買取案内サイトです。ゲーム・CD・映画DVD・携帯電話の案内、IMEI確認手順、3D表現とカルーセルを含みます。

## 公開方法

GitHub Pages の公開元に GitHub Actions を選択すると、main ブランチの更新時に自動公開します。

## 編集するファイル

- index.html：本文・リンク
- style.css：配色・レイアウト・演出
- main.js：カルーセル・操作
- reviews.json：確認済みのGoogle口コミデータ

Google口コミの原文は未取得のため、reviews.json は空です。実在する口コミを確認してから、投稿者名・本文・原文URL・確認済みフラグを登録してください。仮のお客様の声は掲載していません。

生成した3D画像は買取品のイメージです。実店舗・実商品を撮影した写真ではありません。
