# 店長プロフィールの編集方針

- 提供原稿の氏名・読み仮名・生年・出身地・JA勤務・開業日・各店舗の広さを保持。
- 2026年10月時点では開業から満28年未到達のため、継続年数の断定を「1998年創業」「Since 1998」に変更。
- 人柄が伝わる中学生時代の夢と開業時の体験は本文に残し、詳しい経緯はネイティブ details 要素に整理。
- 全商品が必ず買取対象になる表現を避け、対象・条件への案内を掲載。
- 写真は会話上で確認できるものの、アップロードファイルが実行環境および Library で取得できなかったため未掲載。別人や生成の顔写真で代替していない。再添付を受け取ったら manager-card 内に元写真を掲載する。
- 以前GitHub版で実施したレスポンシブ・ハンバーガー・下部固定メニュー・LINE準備中ボタンをSites版にも同期。
